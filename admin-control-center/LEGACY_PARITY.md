# Legacy Operations → Final Control Center parity

The final Afghan Eats administrator workspace preserves every administrator-facing feature from the former `/operations` deployment while keeping newer controls.

| Former Operations feature | Final Control Center location |
| --- | --- |
| Live orders | Orders & dispatch |
| Recent completed/cancelled order history | Orders & dispatch |
| Manual rider assignment | Orders & dispatch |
| Full recent delivery assignment board | Orders & dispatch |
| Delivery assignment status updates | Orders & dispatch |
| Restaurant applications and application history | Restaurants |
| Review / approve / waitlist / reject restaurant applications | Restaurants |
| Rider applications and application history | Riders & shifts |
| Review / approve / waitlist / reject rider applications | Riders & shifts |
| Rider fleet and availability | Riders & shifts |
| Marketplace open / close | Overview + Public site |
| Automatic dispatch | Overview |
| Rider availability approval / rejection | Riders & shifts |
| Create named Rider shift | Riders & shifts |
| Publish open Rider shift | Riders & shifts |
| Rider time-off review | Riders & shifts |
| Rider support inbox | Riders & shifts |
| Owner / Rider activation invites | Portal access |
| Enable / disable portal accounts | Portal access |
| Restaurant listing activation from portal access | Portal access |
| Customer accounts | Customers & rewards |
| Phone-verification state, joined date, referral code | Customers & rewards |
| Loyalty earning / referral settings | Customers & rewards |
| Promotion creation | Promotions |
| Promotion activation / pause | Promotions |
| Minimum order, usage count and usage limit | Promotions |
| In-app service / promotional broadcasts | Communications |
| External messaging provider state | Communications |
| Customer support queue | Customer support |
| Admin password change | Security |
| One-time admin reset link | /admin-reset |
| Operations audit | Audit |
| Audit action details | Audit |

The final Control Center also adds restaurant owner setup review, account recovery, Careers, public incidents, shift-aware dispatch eligibility, and other controls that did not exist in the former Operations page.

Public customer/partner forms that happened to share the old JavaScript bundle are not administrator features and remain on their public routes instead of being duplicated inside the admin workspace.
